# 純正（Claude Code）との対応

方針: **Claude Code の純正機能でできることは、純正に寄せる。** 紡は「純正に無いところ」だけを持つ。
毎日の追従（紡の開発セッションの定時）で見直し、純正でできるようになったら紡から外す。

最後に見直した版: 2.1.326（2026-11-17 08:4x の追従）

| やりたいこと | いまの純正 | 紡がやっていること | 純正に寄せられない理由・メモ |
|---|---|---|---|
| 背景でセッションを動かす | `claude --bg`・`/bg`・agent view | 起こすときに `--bg` を使う | 寄せている |
| 止まったら起こし直す | 無い（`claude daemon` のサービス登録は無効） | `run` を OS の定期実行（5 分おき）で回す | 純正にできたら外す |
| 放っておくと退役する | agent view の Ctrl+T（ピン留め）で残す | 退役したら同じ会話のまま起こし直す | ピン留めを CLI から付けられれば寄せる |
| 決まった時刻に指示を渡す | セッション内の CronCreate（セッションが消えると消える・7 日で切れる）／クラウドの routines | `定時` | 手元で・セッションをまたいで残るものが無い |
| 外から指示を渡す | セッション間の SendMessage（Claude からのみ） | `届ける` | CLI・スクリプトから渡す口が無い |
| 止まったままを見張る | 無い | `見張り`（`claude agents --json` の state / status） | |
| セッション一覧 | `claude agents --json` | 一覧はこれを使う。所属と番号を足すだけ | 寄せている |
| 前面と背景の行き来 | `claude attach`・agent view | `attach` は止まっていれば起こしてから開く | |
| 知識をまたいで持つ | 自動メモリ（手元・プロジェクトごと） | 切る。結（yui）に置く | 所属・マシンをまたいで同じものを引くため（鈴木さんの方針） |
| Claude Code の更新 | native の自動更新・`claude update` | `更新` で `claude update` を呼ぶだけ | 寄せている |
| 動いているセッションを新しい版へ | `claude respawn <id>\|--all`（2.1.326 で確認。CHANGELOG には載っていない） | `入れ直し` は「どれが古いか・空いているか」を選んで `claude respawn` を呼ぶだけ | 寄せた（同じ会話 ID・同じ名前のまま。実測） |
| 指示を付けて起こす | `--resume <id> "<指示>"`（止まっている会話へ） | 定時・届け | ★起こしたときと違う版で渡すと写し（新しい ID・中身から付く名前）になることがある。紡は会話 ID で追い、写しを引き取る |
| OS の更新 | 対象外 | `更新` の `OS`（apt / brew / winget） | |
| 設定項目の追従 | 公式 docs・SchemaStore | `設定項目`（一覧の増減と、一覧に無い鍵） | 一覧は SchemaStore（公式 docs の写し・遅れることがある） |
